# L1 Vietnamese (Tiếng Việt) → German interference patterns

Explanations follow the chat-language rule in SKILL.md; the L1 contrasts below apply either way.

| Code | Pattern | Why (VI contrast) | Wrong → Correct |
|---|---|---|---|
| CONJ | Verb not conjugated | VI verbs never inflect | Er gehen jeden Tag arbeiten. → Er **geht** … |
| TENSE | Tense only via time words | VI marks time with *đã/sẽ* or adverbs | Gestern ich gehe ins Kino. → Gestern **bin ich** ins Kino **gegangen**. |
| PLURAL | No plural form | VI nouns do not inflect, and plural is shown with *các/những* | zwei Buch → zwei **Bücher** |
| ARTICLE | Articles missing / classifiers | VI uses classifiers (*cái, con*), not articles | Ich kaufe Tisch. → Ich kaufe **einen** Tisch. |
| GENDER | Gender guessed | VI has no grammatical gender | |
| CASE | Case endings ignored | VI has no case at all | Ich sehe der Mann. → Ich sehe **den** Mann. |
| ADJ-POS | Adjective after the noun | VI: *nhà lớn* (house big) | das Haus groß → das **große** Haus |
| V2 | Topic–comment order | VI puts the topic first, with SVO | Am Montag ich habe Unterricht. → Am Montag **habe ich** … |
| SUBORD | Verb-final order not applied | there is no clause-final verb in VI | …, weil ich bin müde. → …, weil ich müde **bin**. |
| QUESTION | Question particle instead of inversion | VI uses *không/chưa* at the end of the question | Du hast Zeit, nicht? (casual) → **Hast du** Zeit? |
| SPELL | Final consonants and clusters dropped | VI syllables rarely end in consonant clusters | Herbst → *Herb*, nicht → *nich* |
| COPULA | *sein* with adjectives missing | VI adjectives work as predicates (*tôi mệt*) | Ich müde. → Ich **bin** müde. |

**Teaching tips for VI learners:**
- Conjugation tables with ich/du/er, and drill them aloud daily.
- Every noun as a triplet: article + noun + plural.
- Word order puzzles: give the sentence parts and let the learner build V2 and verb-final sentences.
