# L1 Hindi (हिन्दी) → German interference patterns

Explanations follow the chat-language rule in SKILL.md; the L1 contrasts below apply either way. Many Hindi speakers also know English, so check `en.md` too.

| Code | Pattern | Why (HI contrast) | Wrong → Correct |
|---|---|---|---|
| VFINAL | Verb at the end of a main clause | HI is SOV (*मैं स्कूल जाता हूँ*) | Ich in die Schule gehe. → Ich **gehe** in die Schule. |
| V2 | Subject before the verb after a fronted element | there is no V2 rule | Morgen ich habe Prüfung. → Morgen **habe ich** eine Prüfung. |
| ARTICLE | Articles missing | HI has no articles | Ich habe Idee. → Ich habe **eine** Idee. |
| GENDER | Neuter missing, HI gender transferred | HI has only m/f | *किताब* (f) → die Buch ✗ → **das** Buch |
| PREP | Postpositions → prepositions | HI *में / पर / को* come after the noun | *Ich wohne Berlin in* → Ich wohne **in** Berlin. · Ich gebe es zu ihm. → Ich gebe es **ihm**. |
| CASE | Dative/accusative confusion | *को* covers both the recipient and the definite object | Ich helfe meinen Bruder. → Ich helfe **meinem** Bruder. |
| PROGRESSIVE | Progressive transfer | HI *रहा हूँ* and English -ing | Ich bin am Lernen Deutsch. → Ich **lerne** (gerade) Deutsch. |
| EXPERIENCER | Dative-subject constructions | *मुझे भूख लगी है* = "to me hunger" | Mir ist Hunger. → **Ich habe** Hunger. · but: Mir ist kalt ✓ |
| FALSE_FRIEND-EN | English-based false friends | Hinglish vocabulary | Ich will ein Gift kaufen (= present) → ein **Geschenk** · bekommen ≠ become |
| REGISTER | *आप/तुम/तू* vs. *Sie/du* | Hindi has 3 levels while German has 2, so learners mix forms inside one text | keep Sie consistent in formal letters: **Ihr**, **Ihnen** |
| QUESTION | Question word position | HI puts *क्या* at the start and keeps SOV | Wann du kommst? → Wann **kommst du**? |
| CAPS | Nouns in lowercase | Devanagari has no capital letters | |

**Teaching tips for HI learners:**
- The HI SOV order matches the German subordinate clause, so start subordinate clauses early as a positive transfer.
- In main clauses, drill "verb to position 2".
