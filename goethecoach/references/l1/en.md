# L1 English → German interference patterns

Explanations follow the chat-language rule in SKILL.md; the L1 contrasts below apply either way.

| Code | Pattern | Why (EN contrast) | Wrong → Correct |
|---|---|---|---|
| V2 | SVO kept after a fronted element | EN keeps subject–verb order | Tomorrow I go to Berlin → Morgen ich fahre … → Morgen **fahre ich** nach Berlin. |
| SUBORD | Verb not final in a subordinate clause | EN has no verb-final rule | …, weil ich habe keine Zeit → …, weil ich keine Zeit **habe**. |
| SATZKLAMMER | Participle/infinitive not at the end | EN keeps the verb group together | Ich habe gekauft ein Auto. → Ich habe ein Auto **gekauft**. |
| GENDER | Article/gender guessed | EN "the" has no gender | das Mann → **der** Mann |
| CASE | Case endings ignored | EN has case only on pronouns | Ich sehe der Hund. → Ich sehe **den** Hund. |
| FALSE_FRIEND | False friends | shared Germanic roots | bekommen ≠ become (→ werden) · also ≠ also (→ auch) · Gift ≠ gift · eventuell ≠ eventually · aktuell ≠ actually · sensibel ≠ sensible · Chef ≠ chef |
| TENSE-SEIT | *seit* + Perfekt | EN present perfect ("I have lived here for 3 years") | Ich habe hier seit 3 Jahren gewohnt. → Ich **wohne** hier seit 3 Jahren. |
| PROGRESSIVE | -ing transfer | there is no progressive form in German | Ich bin lesend. → Ich **lese** (gerade). |
| WENN-WANN-ALS | *when* has 3 translations | EN "when" covers all 3 | Wenn ich jung war → **Als** ich jung war · Wenn kommst du? → **Wann** kommst du? |
| STATE | "I am cold / hot" | EN uses the subject + be | Ich bin kalt. → **Mir ist** kalt. |
| MAKE-DO | *machen* overused | EN "make/do" collocations | eine Entscheidung machen → **treffen** · ein Foto machen ✓ |
| CAPS | Nouns in lowercase | EN capitalises proper nouns only | |
| REGISTER | du/Sie | EN "you" has no register | keep Sie consistent in formal texts |

**Teaching tips for EN learners:**
- The vocabulary overlap is an advantage, but the false friends list is exam-critical.
- Focus on word order (V2, the verb bracket) and the case system (article tables).
