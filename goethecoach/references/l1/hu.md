# L1 Hungarian (magyar) → German interference patterns

Explanations follow the chat-language rule in SKILL.md; the L1 contrasts below apply either way. Use the pattern codes in the error list.

| Code | Pattern | Why (HU contrast) | Wrong → Correct |
|---|---|---|---|
| V2 | Verb not in 2nd position | HU word order is driven by focus and is free, while in German main clauses the finite verb is always in 2nd position | Heute ich gehe in die Schule. → Heute **gehe ich** in die Schule. |
| SUBORD | Verb not at the end of a subordinate clause | HU has no verb-final rule after *hogy/mert/ha* | …, weil ich habe keine Zeit. → …, weil ich keine Zeit **habe**. |
| PRODROP | Subject pronoun missing | HU marks the person on the verb (*megyek*), so the pronoun is dropped | Morgen komme nicht. → Morgen komme **ich** nicht. |
| PLURAL | Singular after a number | HU: *három könyv* (singular after numbers) | drei Buch → drei **Bücher** |
| GENDER | Article or gender guessed | HU has no grammatical gender (*ő* = he/she) | das Tisch → **der** Tisch · Meine Bruder → Mein Bruder |
| CASE | Wrong case after a preposition or verb | HU expresses relations with suffixes (*-ban, -nak*), and the German preposition + case pairs are memorised wrong | mit der Freund → mit **dem** Freund · Ich helfe dich → Ich helfe **dir** |
| PREP | Suffix-to-preposition mapping | *-ra/-re, -ba/-be* do not map 1:1 to *auf/in/nach/zu* | Ich fahre in Deutschland. → Ich fahre **nach** Deutschland. |
| REFLEXIVE | Reflexive pronoun missing or wrong | HU reflexive verbs mostly lack a separate pronoun (*örül, emlékszik*) | Ich freue auf … → Ich freue **mich** auf … |
| REGISTER | du/Sie confusion | HU *te/ön/maga* have a different, looser distribution, and people often mix forms inside one text | Sehr geehrte Frau Weber, kannst du … → **können Sie** … |
| FALSE_FRIEND | False friends | shared German loanwords with a changed meaning | *kollégium* → Kollegium ✗ → **Studentenwohnheim** · *blokk* → Block ✗ → **Kassenbon** · *akció* → Aktion ✗ → **Sonderangebot** · *szimpatikus* = sympathisch ✓ |
| NEG | *nicht/kein* choice and position | HU *nem* covers both | Ich habe nicht Zeit. → Ich habe **keine** Zeit. |
| CAPS | Nouns in lowercase | HU capitalises only proper nouns | die schule → die **Schule** |

**Teaching tips for HU learners:**
- Build a "Satzklammer" picture: Position 2 = verb, end = infinitive / participle / verb in a subordinate clause.
- Learn nouns only with the article and plural (*der Tisch, -e*).
- Contrast "Ich fahre **nach** Berlin / **in** die Schweiz / **zu** meiner Oma" as one memory chunk.
