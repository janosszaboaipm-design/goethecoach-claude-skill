# Any other native language — how to find interference patterns

Use this when the learner's L1 has no dedicated file. First check whether the learner also speaks a language that has one (e.g. English), and use that as well.

## Step 1 — Check these typological features of the L1 (from your own knowledge)

| Feature of the L1 | Expected German error | Pattern code |
|---|---|---|
| No articles | articles missing, *ein/kein* confusion | ARTICLE |
| No or different grammatical gender | wrong der/die/das | GENDER |
| Few or no cases | case endings after prepositions/verbs wrong | CASE |
| Verb-final (SOV) | verb at the end of main clauses | VFINAL |
| Strict SVO | no inversion after a fronted element | V2 |
| Free word order | V2 and verb-final both unstable | V2 / SUBORD |
| Pro-drop | subject pronoun missing | PRODROP |
| No copula in the present | *sein* missing | COPULA |
| Postpositions / case suffixes | preposition choice or position wrong | PREP |
| No inflection (isolating) | missing conjugation, plural and adjective endings | CONJ / PLURAL |
| Different formality system | du/Sie mixing | REGISTER |
| Non-Latin script / no capitals | capitalisation and spelling of umlauts | CAPS / SPELL |

## Step 2 — Confirm with the learner's text
Only attribute an error to the L1 if it recurs (≥ 2×) and matches a feature above. A single slip is a normal learner error, not interference.

## Step 3 — Explain contrastively
"In your language …, in German …" plus one German example. If you are unsure about a detail of the L1, do not invent it. Explain the German rule on its own terms instead.

## Universal learner errors (all L1s)
- Adjective endings after der/ein/no article
- Separable verbs (*Ich rufe dich an* — the prefix goes to the end)
- Perfekt with *sein* for verbs of movement or change
- Two-way prepositions (Wo? → Dativ, Wohin? → Akkusativ)
- Comma before subordinate clauses
- *dass* vs. *das*
