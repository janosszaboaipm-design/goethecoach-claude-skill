# Schreiben rubric — GoetheCoach v1 (skill edition)

Four criteria, equal weight (25 % each of the task's points; Strukturen takes the rounding remainder). Work through them in this order and **quote the learner's text as evidence** for each.

**Task points** (the scale GoetheCoach uses — use these, don't invent others):

| Level | Teil 1 | Teil 2 | Teil 3 |
|---|---|---|---|
| A1 | 20 (short message) | — | — |
| A2 | 20 (per message) | 20 | — |
| B1 | 40 (informal email) | 40 (forum) | 20 (formal message) |
| B2 | 60 (forum) | 40 (formal message) | — |
| C1 | 60 (opinion piece) | 40 (formal email) | — |
| C2 | 100 (extended text) | — | — |

The A1 form-filling part is scored 1 point per correct field and is not rubric-scored.

**Word count** = whitespace-separated tokens of the whole text, **including** greeting, closing and signature, the same way the GoetheCoach app counts. Count them; don't estimate. State the count in the feedback.

## 1. Aufgabenerfüllung (task fulfilment)

Rule-based — do it mechanically:

1. For every Leitpunkt decide **full (1) / partial (0.5) / absent (0)** and quote the sentence(s) that address it. Partial = mentioned but not developed. Judge content only, not language quality.
2. Coverage = sum ÷ number of Leitpunkte.
3. Format deductions (max −30 percentage points total):
   - required greeting missing or inappropriate: −15
   - required closing missing or inappropriate: −15
   - wrong register (du ↔ Sie, colloquial in a formal letter): −15
4. Length: 50–70 % of the target length: −10. Below 50 %: cap the criterion at 50 %.
5. Blank or completely off-topic text: 0 %, and say that the task is graded E.

Format reminders: informal = "Liebe/Lieber …", du-forms, informal closing ("Viele Grüße", "Liebe Grüße"). Formal = "Sehr geehrte Frau …/Sehr geehrter Herr …/Sehr geehrte Damen und Herren", Sie-forms, "Mit freundlichen Grüßen".

## 2–4. Kohärenz, Wortschatz, Strukturen — band scale

Choose a band per criterion: **5 / 4 / 3 / 2 / 1 / 0.5 / 0**

| Band | % | Meaning |
|---|---|---|
| 5 | 100 | fully meets the level descriptor, no material weakness |
| 4 | 83 | meets it, minor non-impeding issues |
| 3 | 67 | mostly meets it, noticeable issues that do not block communication |
| 2 | 50 | partially meets it, issues start to impede |
| 1 | 33 | below level, frequent issues impede understanding |
| 0.5 | 17 | minimal relevant content at this level |
| 0 | 0 | absent / not assessable |

At **C1** the top of the scale is compressed (5 = 95, 4 = 82, 3 = 65, 2 = 48, 1 = 32, 0.5 = 16).

Between two bands: pick the lower one **only** if you can name an impeding feature that justifies it; otherwise pick the higher.

**Kohärenz** — cite paragraphing, the connectors actually used, logical progression, pronoun clarity.
- 5: clear paragraphs, varied appropriate connectors, unambiguous references
- 3: understandable overall, repetitive connectors or a few jumps
- 1: sentence-list feel, missing/wrong connectors, reader must reconstruct the logic
- A1–A2 need only basic linking (und, aber, dann, weil). B2+ needs subordination and discourse markers.

**Wortschatz** — cite range vs repetition, precision, register fit, level-appropriateness.
- 5: precise, varied, level-appropriate, register right
- 3: adequate, noticeable repetition or a few imprecise/register-off choices
- 1: very limited/repetitive, frequent wrong-word or register errors that impede

**Strukturen** — cite the range of structures attempted and whether errors impede meaning.
- 5: wide range, errors rare and non-impeding
- 3: simple structures dominate, noticeable errors, some impede
- 1: frequent errors that impede understanding
- Apply these steps **in this order**:
  1. Choose the band from the descriptor above.
  2. Cap it at the **error-density ceiling** (errors per 100 words → max band): <3 → 5 · <6 → 4 · <10 → 3 · <15 → 2 · ≥15 → 1.
  3. If **no** error impedes meaning and the band is now below 3, raise it to 3. This floor beats the ceiling.
- Acceptable variants are not errors. This includes Ausklammerung in informal texts ("Ich muss lernen für die Prüfung") and "weil" + V2 in very informal messages. Mention them as style tips at most.

## Level expectations

- **A1:** present tense, basic everyday vocabulary, simple sentences. Register and greeting/closing are first-class requirements.
- **A2:** present + Perfekt, basic connectors (und, aber, weil, dann), everyday vocabulary.
- **B1:** reaching the communicative goal counts most — missing Leitpunkte and register errors weigh more than isolated grammar slips. Perfekt/Präteritum, subordinate clauses, opinion phrases, basic Konjunktiv II.
- **B2:** Konjunktiv II, Passiv, relative clauses, advanced connectors (dennoch, allerdings, infolgedessen), differentiated vocabulary, register awareness.
- **C1:** Partizipialkonstruktionen, Konjunktiv I, Nominalisierungen, complex Passiv, precise register control.
- **C2:** Nominalstil, extended participial constructions, idiomatic precision, academic/literary register. Colloquial language caps Wortschatz.

## Error list

List only errors that are really present, each once: quote → correction → short explanation (in the learner's language) → category → impeding yes/no → L1 pattern code if one from `l1/<code>.md` applies.

Categories: Capitalization, Spelling, Grammar, Punctuation, Article, Preposition, Word Order, Agreement, Tense, Vocabulary, Phrasing/Idiom, Verb Position, Verb Form, Adjective, Conjunction, Negation, Modal, Compound Word.

## From criteria to result

1. Points per criterion = % × criterion maximum (task points ÷ 4).
2. Task total, then module total over all Teile if several were written.
3. Grade letter per criterion, for orientation: ≥90 % A · ≥72 % B · ≥50 % C · ≥30 % D · else E.
4. **Report the total as a range of ±4 percentage points** around your computed value (e.g. 66 % → "ca. 62–70 %"), because an LLM estimate varies between runs. Relate it to the 60 % pass line.
5. Before sending, check the result against the closest example in `assets/calibration-examples.md`. If yours differs by more than one band on a criterion, re-examine it.
